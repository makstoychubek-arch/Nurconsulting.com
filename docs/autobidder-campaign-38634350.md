# Кампания 38634350 — реальная или выдуманная?

Дата проверки: 10.09.2026. Кабинет Zevina 1 (`21cffafa-bca2-4984-b5f8-5c426e6f538b`).  
Источник: `adv_campaigns` на проде + живой WB Advertising API (`GET /api/advert/v2/adverts`, `POST /adv/v0/normquery/list`, `POST /adv/v0/normquery/get-bids`). Токен не печатаю.

**Коротко:** кампания **реальная**, `nm_id` **287679331 настоящий** (не выдуман). Сейчас она **не живая** (`status=7`, завершена). Пустой `items` у `listClusters` — **не потому что пауза / единая ставка / не тот эндпоинт**, а потому что в запрос не передали пару `advertId` + `nmId`. С официальным телом у неё **40 активных кластеров** и **2 живые ставки**.

## 2. Это не одна из живых. Три гипотезы — нет

Черновик пробного правила писал «status 9». На момент этой проверки **38634350 не status 9**.

WB-статусы: `7` = завершена, `9` = активна, `11` = пауза.

Одноимённые / тот же артикул у Zevina 1:

| `wb_campaign_id` | status | тип | оплата | имя |
|---|---|---|---|---|
| **38634350** | **7 завершена** | **manual** | **CPM, поиск** | **287679331 Поиск пиджак квадрат шоко2** |
| 39497283 | 11 пауза | manual | CPM | то же имя, тот же nm |
| 36092103 | 7 завершена | unified (auto) | CPM | `287679331 Пиджак шоко Арген CPM…` |

Живые Zevina 1 сейчас (5 штук, не 3):

| `wb_campaign_id` | тип | оплата | имя | `nm_id` в БД |
|---|---|---|---|---|
| 35179140 | unified | CPM | Кампания от 23.03.2026 | 391102728 |
| 39497221 | manual | **CPC** | СРС пиджак квадратный | 409845462 (+ ещё 409845463 в WB) |

Про три догадки:

1. **«На паузе, хотя status 9»** — нет. У 38634350 status **7**. Пауза — это соседняя **39497283**.
2. **«Кластеры в другом эндпоинте»** — нет. Нужный как раз `POST /adv/v0/normquery/list`. Эндпоинт верный.
3. **«Единая ставка, поэтому кластеров нет»** — нет. У 38634350 `bid_type=manual`, `payment_type=cpm`. Единая — это 35179140 / 36092103.

## 3. Почему `listClusters` вернул пустой `items`

Тело запроса. Спека OpenAPI:

```json
{ "items": [{ "advertId": 38634350, "nmId": 287679331 }] }
```

Что реально уходило и что ответил WB (все вызовы 10.09.2026, тот же токен Zevina 1):

| Тело | HTTP | Ответ |
|---|---|---|
| `{ items: [{ advertId, nmId }] }` — официальное | 200 | `items.length=1`, **40 active + 59 excluded** |
| `{ items: [{ id: 38634350 }] }` — как в PR #86 | 200 | **`items: []`** (тихо, без ошибки) |
| `{ items: [{ advertId: 38634350 }] }` без `nmId` | 200 | **`items: []`** |
| `{ advertId, advert_id }` — старый `sync-campaigns` на `main` | 400 | invalid payload |

Пустой `items` при 200 — WB так отвечает на неполное тело, а не «кластеров нет».  
То же на живой СРС 39497221: `{items:[{id}]}` → пусто; официальное тело → **117 active**.

Примеры активных кластеров 38634350 / 287679331 (не выдумка):

`пиджак для женщин`, `пиджак женский коричневый`, `пиджак женский шоколадного цвета`, `классические пиджак женский`, `блейзер женский приталенный`, …

`get-bids` (тело `{ items: [{ advert_id, nm_id }]}` — в спеке snake_case):

| кампания | ставок |
|---|---|
| **38634350** (завершена, CPM manual) | **2**: `пиджак для женщин` = **420 KGS**, `пиджак женский коричневый` = **420 KGS** |
| 39497283 (пауза, то же имя) | 0 |
| 39497221 (живая СРС) | 0 — кластеры в list есть, ставок CPM нет |
| 35179140 (живая единая CPM) | 0, list: 0 active / 0 excluded |

`setBids` по спеке — только manual + CPM. Живые Zevina 1 сейчас либо СРС, либо единая. **Ни у одной живой нет ставок в `get-bids`.** Кластеры у живых СРС при правильном теле **есть**. Пустая таблица `adv_clusters` — следствие кривого тела синка, не «кластеров нет в природе».

Фраза из черновика `пиджак женский квадратный` в list/get-bids **не встречалась**. Это была заглушка. Для правила она больше не нужна.

## 4. Что брать для пробного правила

По условию: 38634350 реальная → берём **её** и её **реальный** `nm_id`. Кластеры у неё есть — заглушку не ставим.

| Поле | Значение | Откуда |
|---|---|---|
| Кампания | `38634350` | БД + WB |
| `nm_id` | `287679331` | БД + `nm_settings` |
| Кластер | `пиджак для женщин` | `get-bids`, ставка 420 KGS |
| Запасной кластер | `пиджак женский коричневый` | вторая ставка, тоже 420 KGS |

Оговорки (не выдумка, а ограничения пробы):

- Кампания **завершена**. Тик `autobidder-tick` режет только `manual_bid`, статус не смотрит — DRY_RUN по ней пройдёт, `getBids` эти 2 ставки увидит.
- Валюта кабинета — **KGS**, не рубли. Потолок `max_bid=80` из черновика сразу упрётся в текущие 420.
- В БД кампания **уже есть**. Не делать `INSERT … status='active'` — это перетрёт факт `7`.
- Правило в базу **не вставлял**. SQL: `docs/autobidder-trial-rule.md`.
- `DRY_RUN` не снимать.

Если нужна проба именно на **живой** РК: ближайшая по смыслу — `39497221` / nm `409845462` (СРС, 117+ кластеров в list, **0 ставок** в get-bids). Автобиддер CPM-кластеров её не двигает. Живой CPM + manual + ставки сейчас нет.
