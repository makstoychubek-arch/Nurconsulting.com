# Настройки РНП не заходят на лист

Пока открыты настройки, лист РНП скрыт: фотолента и таблица не просвечивают сквозь окно. Фон оверлея непрозрачный, диалог тоже.

В блоке **«Группы в РНП»** группу можно выключить целиком — артикулы не нужно гасить по одному. Блок рисуется всегда, в том числе при повторном открытии.
