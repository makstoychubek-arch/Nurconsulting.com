# Единая геометрия рабочей области (ПК)

Все вкладки Space (РНП, Дашборд, РК, А/Б, Товары, Контент, Агенты, Тарифы…) стоят в одной рамке:

- шапка сверху (`header.app-header`), левое меню (`.sidebar-rail`) с отступом 10px от краёв окна;
- карточка контента: сверху 4px от шапки, по бокам по 6px от краёв рабочей области, **низ вровень с низом левого меню**;
- РНП: карточка лежит внутри `.main-content.rnp-compact`, отступ даёт `padding: 4px 6px 0`;
- остальные вкладки (РК, А/Б, Товары, Контент, Дашборд…, в т.ч. `goods-compact`): `.main-content` сам белая карточка: `margin: 4px 6px 0` снаружи и `padding: 14px 16px` внутри (содержимое не липнет к краям).

Правила живут в `rnp-extra.css` (блок «Единая геометрия рабочей области»). Новую вкладку делать внутри `.main-rail > .main-content`, свои отступы не вводить.
