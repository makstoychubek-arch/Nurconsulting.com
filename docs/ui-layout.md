# Единая геометрия рабочей области (ПК)

Все вкладки Space (РНП, Дашборд, РК, А/Б, Товары, Контент, Агенты, Тарифы…) стоят в одной рамке:

- шапка сверху (`header.app-header`), левое меню (`.sidebar-rail`) с отступом 10px от краёв окна;
- карточка контента: сверху 4px от шапки, по бокам по 6px от краёв рабочей области, **низ вровень с низом левого меню**;
- РНП: карточка лежит внутри `.main-content.rnp-compact`, отступ даёт `padding: 4px 6px 0`;
- остальные вкладки (РК, А/Б, Товары, Контент, Дашборд…, в т.ч. `goods-compact`): `.main-content` сам белая карточка: `margin: 4px 6px 0` снаружи и `padding: 14px 16px` внутри (содержимое не липнет к краям).

Правила живут в `rnp-extra.css` (блок «Единая геометрия рабочей области»). Новую вкладку делать внутри `.main-rail > .main-content`, свои отступы не вводить.


# Телефон (эталонный экран)

**Эталон для проверки мобильной версии: iPhone 393×852 CSS-пикселей, devicePixelRatio 2–3 (скриншоты владельца ~924 px ширины).**
Каждый раздел (Дашборд, РНП: общий / по артикулам / по одному артикулу, РК, А/Б, Товары, Тарифы, Настройки, окна приветствия, инструкции, «Старт») проверяется на 393×852:

- нет горизонтальной прокрутки страницы (`document.documentElement.scrollWidth === clientWidth`), «качания» вбок быть не должно;
- широкие таблицы (РНП по дням, по артикулам) прокручиваются **внутри своего блока**, первая колонка с названиями метрик остаётся закреплённой;
- нижнее меню (`.bottom-nav`) не перекрывает контент: у рабочей области внизу отступ под него;
- кнопки и поля не меньше 40px по высоте, текст не меньше 12px;
- модальные окна не выше экрана и прокручиваются внутри.

Правила для телефона лежат в `rnp-extra.css`, блок «Телефон 393».
