# Отчёт А/Б-теста в Telegram — утверждённый шаблон

Утверждено владельцем 09.10.2026. Менять только по его просьбе; перед отправкой любых правок макета — рендер локально (см. ниже).

**Сообщение — только картинка, без подписи** (подпись пустая). Если картинка не собралась, уходит короткое текстовое сообщение «Название · арт. N».

**Макет (`supabase/functions/_shared/ab-test-report-png.ts`):**
1. Верхняя строка. Слева настоящий логотип NR (`icons/logo-nr.svg`, белый скруглённый квадрат, чёрные буквы; в коде встроен PNG) и чёрным «/ АБ ТЕСТ». Справа юридическое название кабинета (`cabinetLegalName`: «ИП Бейшеев А.Д.», «ИП Уркунбаев К.А.», «ИП Айзада», «ОсОО «Айлин Стиль»»), выровнено по правому краю.
2. Название товара, строка «арт. … · кампания».
3. Строка времени: «Запуск: … · Завершён: … · Длительность: … · причина». Время по Бишкеку.
4. Плашка вердикта (звёзды, «лидирует вариант N»).
5. Карточки всех вариантов в ряд; победитель/«Сейчас на ВБ» в фиолетовой рамке. Фото в формате 3:4 (как карточка WB), без полос.
6. Под фото крупный CTR, дельта к варианту 1 и вероятность, ниже таблица одной ровной колонкой: CTR, CR клик→корзина, CR1 корзина→заказ, Показы, Клики, В корзину, Заказов, На сумму, Затраты, CPC, CPV (показ), На ВБ (мин), Ротаций.
7. Подвал: «Nurconsulting · главное фото WB = слот 1 · дата · ссылка на тест».

**Важные особенности библиотеки canvas** (из-за них раньше «ехала» вёрстка): `textAlign` игнорируется, `measureText` занижает ширину жирного шрифта (~12%). Поэтому выравнивание считается вручную (`textW`, множитель 1.12 для bold), значения — колонкой слева.

**Как проверить макет перед отправкой:**
```
npm i --prefix /tmp/deno deno
/tmp/deno/node_modules/.bin/deno run -A scripts/render-ab-report-sample.ts /tmp/ab-card.png
```
и посмотреть `/tmp/ab-card.png`.

**Отправка:** при завершении теста — автоматически (`notifyTestFinished`); повторно — действие `resend_notify` функции `ab-test-rotate` (service role).
