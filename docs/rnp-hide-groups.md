# РНП: скрыть группу целиком

В настройках РНП есть блок **«Группы в РНП»**. Выключите группу — все её артикулы пропадут из вкладок, сводной и общего. Не нужно гасить карточки по одной.

В списке артикулов ниже группа остаётся: себестоимость, логистику и тоггл «В РНП» по-прежнему можно править.

Список скрытых групп пишется в `rnp_settings.options.hiddenGroups` и не сбрасывается кнопкой «Сохранить параметры».
