# РНП: по умолчанию только этот месяц

Таблица РНП больше не показывает недели прошлого месяца сами по себе. Сразу виден **только текущий месяц** по дням — сентябрь, если сейчас сентябрь.

Чтобы увидеть рядом другой месяц, в шапке справа есть круглая иконка **сравнения** (две колонки):

1. Нажмите иконку.
2. Первая подсказка — **сравнить с прошлым месяцем** (в сентябре это «с августом»).
3. Ниже — другие месяцы за год.
4. После выбора слева появляются недели выбранного месяца и итог, справа остаются дни текущего.

«Только этот месяц» убирает сравнение. Выбор запоминается в браузере, пока сами не смените.

Пока сравнения нет, сетка остатков не сидит в узкой липкой колонке (там больше нет недель августа) — она над таблицей, в полную ширину. Когда сравниваете с другим месяцем, остатки снова в шапке слева, над неделями.

На телефоне стрелки у названия месяца больше нет — сравнение тоже через эту иконку.
