# Вопросы покупателей — автоответ + короткий реплай в Telegram → правка на Wildberries

Карина **сама отвечает** на **все** открытые вопросы WB **во всех кабинетах** за один прогон (все страницы списка, без отсечки 45 дней; мьют чата это не отключает) и кидает в чат отзывов (`TELEGRAM_CHAT_REVIEWS`) **отчёт как у отзыва**: PNG с фото товара и таблицей Вопрос / Ответ + тег (`TELEGRAM_ALERT_USERNAME`, по умолчанию @maraWuW). Если автоответ неверный — реплай на карточку своим текстом: бот поправит ответ на WB.

Автоответ консервативный: без выдуманных дат поставки (для поступления — «в ближайшее время») и без фактов о подкладе, росте, составе. В отчёте строки «Вопрос» и «Ответ».

Примеры правки:

- `завтра` / `через неделю` → «Здравствуйте! Этот товар будет в наличии …»
- `да` на вопрос про подклад → «Здравствуйте! Да, подклад есть.»
- `170` на вопрос про рост → «Здравствуйте! Костюм рассчитан на рост 170.»
- свой текст целиком — бот поставит «Здравствуйте!» и точку, если их нет

Срок в шаблоне всегда с маленькой буквы, даже если в реплае «Через неделю».

Карина в чат больше ничего не пишет. ❤ на вашем сообщении — правка уже ушла на WB (обычно за секунды). 👎 — не ушло. Тишина больше не значит «ушло».

## Как пользоваться

1. В чате отзывов: PNG-отчёт (фото + таблица Вопрос/Ответ) и короткая подпись с тегом `автоответ · поступление|вопрос` и артикулом. Без #nrq.
2. Если надо поправить — реплай **на карточку Карины** (в том числе на PNG с короткой подписью). Если цитата без `reply_to`, комментарий к каналу или карточка и ответ одним сообщением — бот всё равно узнает артикул и отправит PATCH на WB.
3. Сердечко — ушло. 👎 — не ушло.
4. Если сердечка нет — на WB не опирайтесь: ответьте ещё раз реплаем или через Агенты → Вопросы.

В кабинете → BETA → Агенты → Вопросы можно ответить руками.

## Что не делает бот

- Не отвечает в тиме на поступление товара (это чат отзывов).
- Не отвечает на вопросы не про поступление.
- Не берёт «в пути» с WB.
- Не выдумывает срок («через несколько дней») или подклад.

В общем тиме Карина отвечает на **пригласительную** (`пригласительная Baza 996…`) и на короткий пинг («алоо»). Остальное в тиме по-прежнему молчит, чтобы не спамить.

Реплай по поступлению обрабатывают **telegram-webhook** (notify) и **telegram-router?bot=karina**. Пригласительную в тиме берёт **telegram-router** (Карина) и webhook как запасной путь.

Официальная цепочка [Questions](https://dev.wildberries.ru/docs/openapi/customer-communication#tag/questions), токен категории «Вопросы и отзывы»:

| Шаг | Метод OpenAPI | HTTP |
|---|---|---|
| Есть ли непросмотренные | `getV1NewFeedbacksQuestions` | `GET /api/v1/new-feedbacks-questions` → `{ hasNewQuestions, hasNewFeedbacks }` |
| Список неотвеченных | `getV1Questions` | `GET /api/v1/questions?isAnswered=false&take=&skip=&order=` |
| Один вопрос | `getV1Question` | `GET /api/v1/question?id=` |
| Ответ / правка / просмотр / отклонение | `patchV1Questions` | `PATCH /api/v1/questions` |

Пинг непросмотренных **не возвращает сами вопросы** — только флаги. Карточку в Telegram строим из списка неотвеченных: непросмотренные ≠ неотвеченные.

Ответ: `{ id, answer: { text }, state: "wbRu" }`. Старый `POST /api/v1/questions/answer` WB не принимает. Отзывы — отдельный `POST /api/v1/feedbacks/answer`, их не мешаем.
