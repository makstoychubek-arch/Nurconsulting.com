# РНП не прыгает при обновлении

При F5 сразу тот же лист: фильтры, вкладки, фото, таблица. Блоки не сменяются. Подставляются только цифры.

Снимок пишется в `sessionStorage`, `localStorage` и IndexedDB (`nr-rnp-lock`). Если таблица уже на экране, `_paintSheetBody` патчит ячейки и KPI, а не пересобирает HTML. Вкладки после подгрузки фото не перерисовываются.
