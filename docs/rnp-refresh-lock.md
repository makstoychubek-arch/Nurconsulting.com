# РНП не прыгает при обновлении

При F5 / Ctrl+R каркас РНП уже на месте: шапка, вкладки артикулов и таблица прошлого захода. Меняются только цифры.

Последний нарисованный блок пишется в `sessionStorage` (`rnp_shell_<кабинет>`). Пока данные едут, спиннеры «Загрузка РНП», «Загрузка артикулов» и «Рисуем таблицу» больше не подменяют страницу.
