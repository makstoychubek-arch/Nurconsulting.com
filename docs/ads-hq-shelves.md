# РК: сразу активные полки

Экран **РК** больше не дерево автобиддера. Первый кадр — **активные рекламные полки** кабинета из шапки.

## Что видно

- Название полки, тип (Поиск, Каталог / полка, Авто…), статус, расход сегодня и за 7 дней, ДРР.
- Фильтр **Активные** (по умолчанию) и **Все**.
- На телефоне те же полки карточками, без свёрнутой шапки кабинета.
- Автобиддер и журнал ставок спрятаны в блок **Автобиддер и журнал ставок**.

## Почему раньше было пусто

Кнопка обновления только читала базу. Если `advertising_campaigns` пустая, список молчал. Теперь обновление **подтягивает кампании из WB**, затем перечитывает базу. Если в кабинете полок нет совсем — один раз синкается само, плюс кнопка **Подтянуть из WB**.

Кабинет по-прежнему только в шапке, как в РНП.
