# Товары: остатки по дням

В разделе **Товары** (`https://nurcon.kg/goods`) два вида:

- **Сейчас** — живые ФБО / ФБС / в пути / в плане.
- **Остатки по дням** — история склада по артикулам, как в таблице «Зевина 1».

Кабинет тот же, из шапки. Порядок артикулов тот же, что в **Сейчас** (у Уркунбаева — разделы каталога, у остальных — по категории).

## Таблица

Сверху месяц (сейчас **Сентябрь 2026**). Над колонками дней — **зелёный тренд** по сумме склада за дни, где уже есть снимок. Пустые дни в линию не рисуются как ноль.

Колонки: **Артикул | WB | Кол | 01.09 | 02.09 | …** до конца месяца.

- **Кол** — живой ФБО+ФБС прямо сейчас (чтобы сверить сегодняшний снимок).
- **День** — только кэш. Один раз записали — больше не меняется.
- Дни до первого снимка пустые, не ноль. История начинается с **10 сентября 2026**.

В путь WB и «в плане» сюда не входят. Только склад WB РФ (FBO) + склад FBS, плюс.

## Кэш

Таблица `goods_daily_stocks`. Пишет RPC `snapshot_goods_daily_stocks`:

- дата по календарю Бишкека;
- `qty = sum(wb_stocks.quantity)` по артикулу, FBO и FBS отдельно;
- `ON CONFLICT DO NOTHING` — повторно тот же день не перезапишет;
- UPDATE запрещён триггером.

Первый снимок дня делается, когда открываете **Остатки по дням**. Дальше каждое утро после заливки остатков РНП (`rnp-morning-fill`) дописывает сегодняшний день, если его ещё нет.
