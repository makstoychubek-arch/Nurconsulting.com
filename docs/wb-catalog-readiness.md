# Каталог решений для бизнеса WB: готовность NR Space

Источник требований: «Правила размещения сервисов в каталоге», версия 7.1 от 16.10.25 (dev.wildberries.ru/authorized-services). Страницу нельзя читать скриптом (защита от ботов), текст читаем вручную.

## Что даёт размещение
- Лиды с портала продавцов, значок партнёра, OAuth 2.0 для подключения продавцов.
- Токены продолжают работать как сейчас. Платным размещение не станет. Эксклюзивных методов API нет (кроме «Информация о товарах»).

## Требования и состояние (на 29.10.2026)
| Требование | Состояние |
|---|---|
| ≥200 продавцов с оборотом от 50 000 ₽ за 30 дней, либо ≥50 продавцов с суммарным оборотом >100 млн ₽ за 30 дней | не выполняется (подключено 6 кабинетов) |
| Юрлицо или ИП старше 6 месяцев | проверить владельцу |
| Домен старше 6 месяцев, HTTPS, сайт на телефоне | HTTPS есть; срок домена проверить |
| Реквизиты компании на главной или ссылка с неё | нет, добавить |
| Согласованный с WB User-Agent и сервисный секрет во всех запросах | подготовлено: `_shared/wb-user-agent.ts` (секреты `WB_SERVICE_UA`, `WB_SERVICE_SECRET`); UA и секрет выдаёт WB после заявки |
| Только Public API, без Cookie и браузерных методов | аудит 29.10: запросы идут в официальные `*-api.wildberries.ru`; Cookie нет; публичная CDN фото `basket-XX.wbbasket.ru` (картинки и `card.json`) без токена — спросить WB, допустимо ли |
| Автоопределение типа токена и запрет личных токенов | не сделано. У всех 6 текущих токенов в JWT `acc=3`, `t=false`. Что означает `acc=3`, сверить с документацией WB, пока не блокируем, чтобы не отключить рабочие кабинеты |
| Собственная служба поддержки для продавцов | завести контакт поддержки |
| Список IP для вайтлиста | исходящие IP Supabase динамические; нужен прокси с фиксированным IP |

## Что делать по порядку
1. Написать на business-solutions@rwb.ru: порог по продавцам, условия для сервисов из Кыргызстана, нужен ли фиксированный IP, как перейти на OAuth, смысл `acc=3`.
2. Реквизиты на главной, контакт поддержки.
3. Прокси с фиксированным IP для всех запросов к WB.
4. Определение типа токена при добавлении кабинета (после ответа WB).
5. Подавать заявку, когда подключённых продавцов станет достаточно.
