# Кабинет один — сверху

Кабинет выбирается только в шапке (как в РНП).

- **Товары** — без своего списка кабинетов. Остатки ФБО/ФБС/путь/план именно того ИП, что выбран сверху.
- **РК / Командный центр** — тоже только этот кабинет, не все сразу.
- Сменили кабинет сверху — данные на открытой вкладке перегружаются.

Путь: `https://nurcon.kg/goods` и `https://nurcon.kg/advertising`.
