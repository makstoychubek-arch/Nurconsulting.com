# Товары и реклама: кнопки как в РНП

Лупа, сетка Excel и шестерёнка в **Товарах** стоят справа сверху, в одной линии со «Сейчас» / «Остатки по дням». В **Рекламе** круглая иконка обновления в том же месте.

Вкладки стоят под заголовком «Товары» с отступом, не прижаты к шапке. Колонка **WB** узкая, надпись по центру.
