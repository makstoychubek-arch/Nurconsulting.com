# Отчёты WB (раздел «Оцифровка → Отчёты WB»)

Клиент сам загружает отчёты из кабинета Wildberries, система раскладывает их по дням.

Пять видов отчётов (порядок как на странице):
1. Финансовый (ежедневный детализированный) — реализация, комиссия, логистика, реклама, к перечислению.
2. Продажи («Отчёт по данным поставщика») — заказы и выкупы по баркодам и складам, остатки.
3. Динамика продаж — заказы и выкупы по дням и артикулам.
4. Остатки WB (ФБО) — артикул и «Склад WB».
5. Остатки ФБС — до 5 складов продавца, один файл на склад.

Как работает:
- Файлы можно перетащить все сразу. Вид отчёта и день определяются по заголовкам и датам в файле.
- Файл читается в браузере (`wb-reports.js`, без внешних библиотек), на сервер уходят только строки.
- Данные: `report_uploads` (один файл = одна запись: кабинет, вид, день, склад) и `report_rows` (строки). Повторная загрузка за тот же день заменяет прошлую.
- Календарь месяца показывает по каждому дню, сколько из 5 отчётов загружено.
- Страница показывает: итоги дня (как на Дашборде), какие товары продаются лучше (день / месяц), остатки ФБО и 5 складов ФБС, динамику по дням.

Остатки (4 и 5) в файлах без даты, поэтому ложатся на выбранный день.
Отчёт за период из нескольких дней (кроме «Динамики продаж») не принимается: нужен отчёт за один день.
