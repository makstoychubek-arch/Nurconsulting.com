# Страницы не прыгают при обновлении

При F5 / Ctrl+R блоки остаются на месте. Меняются только цифры.

- Нужная вкладка красится ещё до первой отрисовки (не только Настройки): Дашборд не мелькает перед РНП, РК или Товарами.
- Страница больше не гаснет через прозрачность при смене вкладки.
- Карточки и графики держат высоту, пока подгружаются значения.
- В Товарах уже нарисованная таблица не меняется на «Загрузка…».
- В РНП без недель августа фотолента не съезжает влево и не закрывает показатели: левая панель не уже 420px.
