# РНП не показывает чужой кабинет

При смене кабинета (в том числе в PWA на телефоне) сразу свой лист: снимок `rnp_shell_<кабинет>` или пустой каркас. Лист Базы при Зевене не оставляем.

РНП стартует в момент выбора кабинета, не ждёт `loadFromDB` дашборда. Активный артикул пишется отдельно на кабинет (`rnp_active_nm_<id>`).
