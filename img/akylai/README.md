# Скриншоты для инструкции Акылай

Мастер на странице «Агенты» показывает эти картинки на слайдах. Пока файла
нет, вместо него видна заглушка с именем файла. Положите сюда PNG с точно
такими именами (ширина ~1200px):

| Файл | Что на скриншоте |
|---|---|
| `step-1-api-settings.png` | Личный кабинет WB → профиль → «Настройки» → «Доступ к API» |
| `step-2-token-type.png` | Кнопка «Создать новый токен», выбран тип «Персональный» |
| `step-3-category.png` | Отмечена категория «Вопросы и отзывы», галочка «Только на чтение» снята |
| `step-4-expiry-copy.png` | Выбран срок действия, токен создан, кнопка «Скопировать» |
